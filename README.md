## About This Portfolio

This repository contains three C++ programming challenges completed as part of my CodeLab II Programming Skills Portfolio. The challenges helped me practise programming concepts including functions, loops, vectors, classes, pointers and file handling.

## Challenge 1 – CO₂ Calculator

This program calculates the estimated CO₂ emissions produced during a car journey.

- Asks the user to enter the distance travelled in miles.
- Allows the user to select petrol or diesel.
- Calculates CO₂ emissions using the fuel consumption and emission factors.
- Validates user input and displays the result in kilograms.

**C++ concepts:** Functions, loops, conditional statements, input validation and calculations.

## Challenge 2 – Alexa Joke Generator

This program reads jokes from a text file and displays a randomly selected joke when the user enters the command `Alexa, tell me a joke`.

- Loads jokes from `randomJokes.txt`.
- Stores the jokes in a vector.
- Selects a random joke.
- Displays the question first and waits for Enter before revealing the answer.
- Allows the user to exit by typing `quit`.

**C++ concepts:** Vectors, file handling, strings, loops and random number generation.

## Challenge 3 – Book Manager

This program provides a simple library book management system.

- Loads book information from `bookData.txt`.
- Displays all books or searches for a specific book by ID.
- Allows books to be borrowed and returned.
- Updates borrowing status and saves changes to the text file.

**C++ concepts:** Classes, objects, constructors, vectors, pointers, functions and file handling.

## Running the Programs

The programs were developed and tested using Visual Studio Code and a C++ compiler.

Open the main project folder in VS Code, compile the required `.cpp` file and run the program in the terminal.

For Challenges 2 and 3, run the programs from the main `code lab 11` directory so they can access their text files.
